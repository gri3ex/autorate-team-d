# Протокол ретроспективи Спринту 2

**Команда:** D  
**Дата:** 28.10.2026  

## Start (Почати робити)
- Більш активно комунікувати асинхронно в чаті на етапі незалежного аудиту специфікації.
- Заздалегідь узгоджувати структуру папок на GitHub, щоб уникнути плутанини з файлами.

## Stop (Припинити робити)
- Відкладати зведення фінальних документів та оформлення репозиторію на останній вечір перед дедлайном.
- Покладатися лише на один пристрій під час перебоїв з електропостачанням (враховувати резервні варіанти зв'язку).

## Continue (Продовжити робити)
- Проводити якісний незалежний аудит за шістьма чек-листами якості вимог.
- Зберігати чіткий розподіл ролей (КТ, ТА, ІТ, СМ) та взаємодопомогу в команді.
