# bpmn/ — моделі бізнес-процесів спринту 1

## Інструмент

Моделі побудовано в **diagrams.net (draw.io)**, онлайн-версія app.diagrams.net, бібліотека
фігур **BPMN 2.0** (увімкнена через «More Shapes… → Business → BPMN 2.0»). Формат
вихідних файлів — `.drawio` (XML, mxGraph).

## Як відкрити

1. Відкрити https://app.diagrams.net
2. File → Open from → Device → обрати потрібний `.drawio`-файл із цієї папки.
3. Або перетягнути файл просто у вікно браузера з уже відкритим app.diagrams.net.

Редагувати напряму на GitHub також можна — розширення
[draw.io Integration](https://github.com/marketplace/actions) чи плагін для VS Code
відкриває `.drawio` як превʼю, але для редагування зручніший десктопний застосунок
draw.io або веб-версія.

## Файли та чинні версії

| Модель | Вихідний файл | Експорт | Статус |
|---|---|---|---|
| 3.1 Реєстрація і вхід | `01_registration.drawio` | `01_registration.pdf`, `01_registration.png` | чинна версія |
| 3.2 Голосування за модель | `02_voting.drawio` | `02_voting.pdf`, `02_voting.png` | чинна версія |
| 3.3 Модерація коментарів | `03_moderation.drawio` | `03_moderation.pdf`, `03_moderation.png` | чинна версія |

Усі три моделі станом на 05.10.2026 побудовані справжніми BPMN-фігурами (події з
типізованими іконками — повідомлення/таймер/просто, типізовані шлюзи, задачі зі
стандартними маркерами). Жодних дублюючих чи застарілих версій файлів у папці немає —
якщо зустрінете файл із суфіксом на кшталт `changed`, це залишок проміжної правки, який
слід видалити.

## Примітка з історії правок

Модель 3.3 спершу була імпортована з Mermaid-flowchart (усі події виглядали однаковими
колами, без розрізнення типу), через що не проходила чек-лист нотації (§4.9 п.2, п.6).
Її перебудовано вручну прямо в draw.io типізованими BPMN-фігурами — див. `review.md` для
деталей повторного рецензування.
