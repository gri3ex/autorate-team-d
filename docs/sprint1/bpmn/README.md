## Норматив (команда з 4 осіб)

- BPMN-моделей: 3 з 4 процесів легенди — виконано.
- User stories: ≥12 — виконано (12).
- Різних типів шлюзів у наборі моделей: ≥3 — виконано (XOR за даними, паралельний ТА,
  виключне АБО за подіями).
